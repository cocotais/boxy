# KittenN 积木样式

参考：<https://kn.codemao.cn/>，2026-11-26 在编辑器内测量 SVG、字体和输入框。
`kittenn-preview-measurements.json` 保存早期 33 项共有积木在 100% 下的预览宽度对照。
后续新增模式、参数和积木清单的检查方法见测试与视觉回归页。

| 项目                | 参考尺寸 / 当前实现                               |
| ------------------- | ------------------------------------------------- |
| 普通语句 / 控制标题 | 40px 高，左侧 2px 圆角，右侧半圆                  |
| 数值、文本等返回值  | 36px 起，胶囊轮廓；内容变高时自适应               |
| 布尔值 / 布尔空槽   | 带小圆角的六边形                                  |
| 积木盒默认值        | 28px 高，横向最少 28px，文字两边各 6px            |
| 工作区默认值        | 30px 高，数字最少 40px 宽，作为可替换的 shadow    |
| 积木盒空语句槽      | 8px 高                                            |
| 积木盒控制块底栏    | 12px 高，内侧起总宽 40px                          |
| 工作区空语句槽      | 20px 高，内侧 2px 圆角                            |
| 工作区控制块底栏    | 20px 高，内侧起总宽 70px                          |
| 语句槽缩进          | 16px                                              |
| 文字                | 系统无衬线，16px，字重 400；Blockly 中配置为 12pt |
| 上下连接            | 平直，无拼图凸口；保留实际连接与吸附行为          |

控制、运算、变量、列表配色使用参考页读取的主色和边线色。函数等其余分类沿用 Boxy 配色。

渲染规则按结构归纳在 `src/theme/codemao.layout.js`，渲染器与字段不按积木类型名或输入名分支：

| 结构 / 字段角色                            | 通用渲染规则                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| 有值输出                                   | 按输出连接类型选择胶囊或布尔六边形；高度随内容增长                         |
| 只有一个可见数值或文本字段，且没有输入连接 | 独立常量使用外层胶囊和内层编辑框；作为 shadow 时使用单层参数胶囊           |
| 圆形输出，只有一个可见字段且没有输入连接   | 按实际字段宽度加两端半径计算外壳宽度；隐藏的变量绑定字段不占空间           |
| 带语句槽的语句积木                         | 标签放在槽上方的标题栏；按各标题的自然宽度绘制圆形右端，槽缩进统一         |
| 最后一个语句槽之后有纯参数按钮输入         | 作为底部操作区布局；标题中的按钮仍随标题排列                               |
| shadow 内只有一个下拉字段                  | 使用完整胶囊选择区域；普通下拉为矩形选择区域                               |
| 句子中的选择词 / 可拖出的变量字段          | 定义处用 `setAppearance('inline' / 'reporter')` 声明字段角色，共用字段渲染 |
| 积木盒上下文                               | 缩小默认值、空语句槽和底栏；隐藏参数按钮，保留完整模型供拖出时克隆         |

尺寸、字体、箭头和文字测量集中在 `codemao.style.js`，悬停、光标和选中效果在
`codemao.effects.js`。字段、预览与渲染器使用同一套尺寸和测量方法，渲染器不再导入字段注册模块。
积木文字与 KN 一样使用 16px、400 字重、等宽数字特性及 `-webkit-font-smoothing: auto`，
避免继承 Arco 页面级的 `antialiased` 平滑设置；网站其他界面继续使用自身字体规范。

渲染分为“定义声明语义 → 结构与上下文解析 → 测量和绘制”三层：

- `contextMetrics` 统一提供工作区/积木盒的字段、空槽、底臂和预览留白尺寸；
  `describeBlock` 根据连接、可见输入、字段角色解析最小宽度、标题输入、行高及底臂，
  绘制时直接使用解析结果，不在每个渲染钩子里重复判断上下文。
- 字段用 `setAppearance('inline' / 'reporter', palette)` 声明句子词或取值胶囊。
  循环变量与函数参数共用胶囊的测量、文字居中、圆角和上色，配色由定义传入；
  拖出的取值积木使用同一宽度公式。参数字段只负责绑定、弹窗和拖出语义。
- 事件头通过 `initStartHat(block, { body, icon })` 一次声明头部并安装徽标外伸的包围盒规则，
  新事件积木无需复制函数定义中的几何补丁。字段拖出共用 `positionFieldReporter`，
  将字段的屏幕位置换算到工作区坐标，保留统一拖拽反馈。

文案、默认值和函数参数绑定仍属于积木定义；轮廓、尺寸和上色属于公共主题。
这些业务差异通过描述数据传入，不用在通用渲染器中增加积木类型分支。

`src/blocks/definitions.js` 集中声明内置积木的默认值、字段角色、选项和连接约束，
从分类配置读取配色，每种定义只安装一次主题初始化；不再为每项调整叠加 init 包装。
原生字段的校验与变形逻辑继续保留。性质下拉直接使用独立的选项文案，不在运行时拆解中文句子。
预览标签通过具名配置声明留白、背景、最小宽度和形状，复用同一套测量与文字居中规则。

简略预览的文案、保留哪些参数、字段是句子的一部分还是参数控件，属于积木定义的语义，
无法仅由形状推断。`src/blocks/flyout.js` 用 `boxyPreview` 描述这些选择，并挂在定义上；
复用定义的新积木会一起继承。几何布局仍由结构决定，无需在渲染器中增加积木名分支。
图标的视觉留白也由图标自身声明，渲染器不识别“列表”等具体业务含义。

工作区与积木盒默认按 1:1 显示，和 KittenN 的 100% 视图一致。
40px 的语句积木现在实际显示为 40px；相较之前的 0.8 倍显示放大 25%。
积木盒固定使用 1:1 比例，工作区可以单独缩放，重置缩放回到 100%。

独立数值和字符串参照 KN“连接”减少到一个参数后的形态，去掉文字和加减号：
36px 高的返回值外壳包住深色胶囊输入框，左右各留 18px。
工作区输入框高 30px、宽度最少 40px，文字两侧各留 15px；积木盒内高 28px、
宽度最少 28px，文字两侧各留 6px。嵌入其他积木的默认 shadow 仍使用单层参数胶囊。
通过字段渲染区分这两种状态，保留 `math_number.NUM`、`text.TEXT` 和原有代码生成、文件格式。

积木盒使用简略预览，工作区使用完整可编辑形态。空的“永远循环”在积木盒中高 60px，
拖入工作区后高 80px。加减乘除、比较及且/或预览显示符号；
舍入、余数、整除、质数、文本等预览仍保留相应默认参数，部分复杂块只显示简短名称。
“遍历”预览保留起止值，隐藏变量和步长；加减号控件只在工作区显示。
`src/blocks/flyout.js` 只隐藏预览中的输入和字段，不删除模型或默认值。
拖出时通过 Blockly 原生序列化克隆恢复完整定义，隐藏的参数、变量、步长和默认值仍被保留。

运算符预览使用 `src/assets/operator-icons.json` 中的 KN SVG 几何，统一以 18px 显示，
保留各图标原有的圆角、线宽和比例；字段槽位尺寸保持不变。
图标按 OP 字段的运算枚举取值，不依赖本地化文字或系统字体；余数积木复用同一除号。

数值性质判断将“是”作为独立文字，性质下拉仅显示“质数”“偶数”等选项；
“分开成列表”和“转换数据类型”在运算分类末尾单独成组，组前使用统一的 38px 分隔留白。

“退出循环／跳过本次循环”保留下方语句连接口，使用普通语句的底边轮廓，可以继续拼接积木；
生成代码仍分别为 `break` / `continue`，执行时遵循循环控制语义。

设置中的“短积木模式”默认开启，偏好以 Cookie 保存。关闭后重建当前积木盒的展示，
展开参数、遍历当前变量及加减按钮；仍保留积木盒的 28px 默认值、8px 空语句槽和紧凑底栏，
不使用工作区的 30px 参数与 20px 空槽。嵌入标题的变量胶囊为 34px，高度与 40px 标题适配；
工作区变量胶囊仍为 36px。符号运算继续使用简略符号入口，完整模式增加幂、≥、≤ 三个预设。
盒内下拉预览隐藏箭头，文字按实际字段宽度居中；“？”等短占位在 28px 最小宽度中保持居中。
作为默认值的下拉空缺与数值、文本默认值共用 28px 高及文字两侧 6px 的胶囊测量；
“？”列表空缺为 28×28 圆形，填充父积木深色的 50% 透明度，边线为黑色 10% 透明度。
脚本变量仍使用 KN 的标题预览，字符选择保留其简略句式。
定义通过 `boxyPreview.expanded` 声明完整模式的特殊预览，通过工具栏 `expandedOnly` 声明额外入口；
两种模式共用几何规则，切换不修改工作区积木或撤销记录，拖出后都恢复同一完整模型。

变量与列表分类按 KN 动态显示取值积木：通用操作预览始终保留，每个已创建的变量或列表
在分类末尾单独显示名称，按创建顺序倒序排列。尚未创建时显示一个通用取值预览，
创建后以实际名称替换；打开积木盒不会创建变量或列表。两个分类分别提供新建入口，
弹窗结束后恢复当前分类，新建、重命名、删除通过 Blockly 变量事件刷新。
列表使用 Array 类型变量及原有 `boxy_list_input` 块，字段参与变量引用追踪，
以便重命名、删除、序列化和代码生成保留绑定。

侧栏的显示、宽度和坐标由自定义 `FixedScaleFlyout` 通过 Blockly 定位接口控制。
`src/blocks/flyout-layout.js` 集中管理固定宽度、1:1 比例和滚动留白：短模式 208px，
完整模式 272px，切换分类或悬停不改变背景宽度。超长积木平时裁切在面板内，
鼠标移入积木盒时才允许横向伸到工作区，纵向仍裁切在视口内；伸出部分可以直接拖动。
旧的“适应／固定”宽度设置已移除。选中分类使用自身图标颜色作为背景，文字保持白色。
积木盒上下内边距为 24px，布局与滚动范围同步增加；左右留白及积木之间的间距保持原规则。
不再用 MutationObserver 重写 SVG 坐标。
`src/blocks/flyout-motion.js` 按 KittenN 的实际动画实现：展开和收起均使用 300ms、ease-out，
整块面板沿水平方向移动一个面板宽度，不使用遮罩或透明度变化。
切换已展开的分类直接替换内容，不重复开合；中途反向从当前位置继续滑动。
收起通过不可交互的临时视觉副本继续播放，Blockly 的原面板立即退出交互。
动画中按下积木会暂停当前位置；拖拽克隆读取 SVG 的实际屏幕矩阵，正确转换到工作区比例，
避免 Blockly 使用最终 inline translate 坐标造成跳动；键盘放置沿用原生坐标计算。
遵循系统的减少动态效果设置，销毁工作区时清理动画及临时副本。

参数交互：

- `src/blocks/fields.js` 实现数值、文本、30px 下拉字段和可替换的列表选择器。
- `src/blocks/mutations.js` 提供共用的 20px 圆形参数按钮及增减操作的撤销事件分组。
  删除动态输入统一释放普通积木；可重复参数、可选返回值及条件分支共用 shadow 状态保存与恢复，
  避免撤销参数移除时把已编辑的文字/数值恢复成默认值。形状状态由各积木声明，值恢复不识别积木类型或输入名。
- 数值/文本编辑时全选内容，白底深色文字，内侧描边使用父块主色；外围白色圆角外圈在 250ms ease 内扩展至 3px，随工作区比例缩放，并遵循减少动态效果设置。Enter 提交、Escape 取消时一起清除外圈。
- 下拉菜单与网站的 Arco Dropdown 共用主题规范：160px 最小宽度、36px 行高、上下 4px 留白，
  `--border-radius-medium` 圆角、`--color-bg-popup` 背景、`--color-fill-3` 细边框及 0 4px 10px 阴影。
  悬停和键盘高亮使用 `--color-fill-2`，文字使用 `--color-text-1`，禁用使用 `--color-text-4`，
  当前选项字重 500；不再使用固定淡蓝底或紫色指示条，随网站明暗主题切换。
  右键菜单使用同一套规范，最小宽度为 200px；快捷键为 12px 次级文字，分隔线跟随主题。
  样式集中在 `src/theme/codemao.menus.css`，覆盖原生焦点阴影，保留 Blockly 的菜单操作、
  方向键导航、Enter 选择、Escape 关闭和视口边界定位。
  右键菜单保留 Blockly 的 content-box 高度约定，避免边框挤占内容高度而产生多余滚动。
- 矩形与胶囊下拉区域统一使用 30px 高度、至少 50px 宽度及文字宽度加 30px 的留白。
  展开时选择区域为白底、1.5px 分类色边线、2px 白色外圈，文字变为 #333、箭头变为边线色；
  胶囊选择器整块变色，关闭后恢复深色底和 0.6 透明度的白箭头。矩形区域恢复白色 10% 透明背景。
- `src/blocks/parameters.js` 实现文本连接和临时列表的末尾加减号，“如果”的否则/否则如果分支，以及遍历间隔开关。
- `src/blocks/procedures.js` 只保留统一函数定义，加减号位于标题参数末尾，复用同一组 20px 圆形按钮；
  加号弹出名称输入框，确认后才创建参数；取消不创建，空名称和同一函数内重名会提示。
  减号移除最后一个参数，保留参数身份、调用处同步与序列化。积木盒不显示按钮。
  普通执行与取值调用只显示函数名和参数输入槽，不显示参数名称及“使用”前缀；参数名称保留在定义与绑定模型中。
- 函数定义采用 KN 事件头的圆形徽标与横向标题栏，左侧白色圆徽标显示积木盒同款 Fx 图标。
  `src/assets/category-icons.json` 为分类图标与事件头提供同一份 SVG 数据；定义通过 `boxyHat.icon`
  声明图标，渲染器不识别具体分类、不依赖系统字体。图标使用分类主色，白色圆徽标保持不变。
  标题主体高 40px，带 36px 参数时为 44px，徽标额外向上突出 8px、向左突出 24px。
  函数体连接点为主体左下角 `(0, 40)` / `(0, 44)`，不把徽标外伸尺寸算入连接偏移。
  函数体左侧缩进为 0，不绘制 C 形竖边、底臂或固定返回条。
  定义通过 `boxyHat` 声明头部及 `STACK` 函数体输入；徽标外伸计入包围盒，积木盒不会裁切徽标。
- `src/blocks/returns.js` 提供独立的无条件“返回”积木，没有条件输入。
  默认带一个 `VALUE` 输入，末尾减号移除返回值，加号恢复默认数值 0；只允许零个或一个返回值。
  零参数生成 `return;`，一个参数生成 `return 表达式;`，参数状态参与保存及撤销重做。
  返回块下方无连接口，最小宽度 110px、左下角 12px 圆角，可在函数体及其中的分支中使用。
  放到函数外会提示并禁用，接回函数后自动恢复。函数可普通调用，也可作为返回值调用。
  带固定返回区的定义及“如果……返回……”积木均已移除，不提供旧格式迁移。
- 工作区中语句积木（含短名称函数调用）的最小宽度统一为 110px，标题超长时按内容扩展。
  值输出积木仍按自身胶囊/菱形规则测量；积木盒保留简略布局与控制块 80px 最小标题宽度。
- `src/blocks/procedure-parameters.js` 把定义中的参数呈现为 36px 胶囊，采用 Kitten4 的函数参数配色：
  填充 `#ff7e2e`、描边 `#e67129`、白色文字；拖出的取值积木共用 `procedure_parameter` 样式。
  点击胶囊弹窗重命名，拖动则创建同名取值积木，定义与原参数仍保留。
  拖出前后共用文字测量和胶囊宽度，可连接到数值、字符串等值输入。
  取值积木用函数与参数 ID 绑定，参数改名时同步更新；复制整段函数时优先绑定到所在的副本，
  文件保存恢复保留绑定。移除参数后原取值积木显示警告，撤销移除可恢复；失效引用生成 `null`。
  参数模型只由函数定义持有，不注册到全局 VariableMap；新建、改名、调用和保存恢复都不会新增全局变量。
  参数取值与调用积木不向变量 API 暴露形参；右键创建参数取值块也使用同一局部绑定。
  生成器为每个函数分配独立的参数名称空间，不生成形参的全局 `var` 声明，同名全局变量互不影响。
- 遍历的当前变量使用独立蓝色胶囊，可以拖出绑定同一变量的取值积木，原循环保留。
- 移除参数/分支会释放连接的非 shadow 积木，其他参数、分支和连接继续保留。
- `src/blocks/definitions.js` 为所有现有值输入配置可替换的默认值。列表参数支持新建或选择 Array 类型变量。
- 操作记录在 Blockly 事件组中，沿用原生撤销重做、连接预览和序列化。连接占位沿用参考页的黑色 20% 透明填充。

拼接占位使用语句结构的简化剪影：普通语句为 110×40，单语句槽控制块为 110×80，
多个语句槽按相同的槽与分隔栏规则扩展。渲染器只测量标题空栏和语句槽，不测量参数、文字、
图标或末尾按钮；默认 shadow 留在模型中供原生连接逻辑使用，视觉上完全隐藏。
剪影只显示主轮廓路径，填充为黑色 20%，边线为黑色 28%；内部胶囊、下拉框和连接装饰均不显示。
主轮廓的 `fill-opacity` 为 1，避免再次叠乘 Blockly 默认的占位透明度。
语句连接不绘制凹凸接口高亮，避免平直接口左上角出现常驻白点；值输入保留替换高亮。
离开拼接位置时通过原生预览器移除剪影并恢复槽位尺寸。

`src/theme/codemao.dragging.js` 统一拼接、拆开反馈。拼接后显示 150ms 线性扩大的白色实心光点，
半径从 0 到 15px（随工作区比例缩放），同时淡出；语句连接处光点位于积木左侧，
值输出沿用连接点偏移。拆开直接跟随拖动，不播放 Blockly 默认的 200ms 倾斜摆动。
减少动态效果时仍保留连接和声音，省略光点。原生连接检查、键盘放置、撤销重做与事件分组保持不变。
该模块使用 Blockly 13 的拖拽反馈方法；升级 Blockly 时需重新执行拼接/拆开浏览器回归。
工作区通过 `CodemaoDragger` 安装策略；积木盒拖出和循环变量拖出复用同一反馈，
自定义积木显式安装的其他拖拽策略不会被覆盖。
循环变量、函数参数和脚本变量共用 `installFieldReporterDrag`；
字段用 reporter 角色声明命中区域，积木定义只提供对应模型的创建函数。
按下时根据命中的 SVG 查找实际字段，不在 SVG 初始化时缓存字段名，
因此通过加号新增的函数参数、脚本变量也可以立即拖出，不需要重新加载作品。
监听、源积木保留和坐标换算由公共策略处理，不再为三种字段分别实现拖拽类。

悬停效果使用参考页的 SVG 滤镜参数：白色外缘模糊半径 1，阴影模糊半径 6、
向下偏移 2、透明度 0.4，积木的原色和 1px 细边线保持不变。
数字和下拉字段沿用细边线，悬停默认数值时高亮父积木；嵌套时只高亮鼠标所在的积木。
每个工作区单独保存滤镜引用，图片导出的临时工作区不会覆盖主工作区的悬停效果。
按下和选中时保留 Blockly 的选中状态，但不绘制 Zelos 的紫色选中叠层；
拖拽沿用白色外缘和柔和阴影，整组拖动时只为最外层积木绘制一次。
积木本体、可编辑字段、默认值胶囊、空槽及文字箭头统一显示 pointer，包含积木盒预览；
避免圆角、菱形斜边处命中外层本体时从 pointer 切换为 grab。
连接高亮的装饰路径不参与鼠标命中。
拖拽及禁用状态保留 Blockly 原生光标，真正的 HTML 输入框保留文本光标。

`src/theme/codemao.renderer.js` 基于 Blockly 13 的 Zelos：

- `CustomConstantsProvider` 应用共用尺寸、字体、输入框和布尔轮廓。
- `CustomRenderInfo` 读取结构描述，将语句输入标签移到槽上方，并测量标题和底栏。
- `CustomDrawer` 绘制语句块及控制块的半圆右侧；返回值沿用 Zelos 的动态轮廓。
- `CustomPathObject` 统一默认值和空槽颜色。

外置值输入仍由 Zelos 绘制，以保留非内联布局的输入连接口。
普通积木保留 Boxy 的块类型和字段/输入名称；函数使用统一定义、独立返回及共用的参数视觉规范。
没有 KN 对应项的 Boxy 积木使用相同轮廓、字体、参数和菜单规范，不引入 KN 的角色运行时。

运算、变量与列表的入口清单另见 `kittenn-block-inventory.md`。四则运算、比较及且／或
分别提供 KN 的预设；独立数值和字符串按用户要求保留。变量与列表不提供显示／隐藏，
不再展示额外文本处理、单独空列表、遍历列表与条件取值入口。
`variables.js` 定义脚本变量声明和可拖出的取值块，字段复用 reporter 外观、参数按钮和拖出坐标换算；
变量下拉同时提供全局变量与声明之后可见的脚本变量，局部绑定以 ID 保存，不创建全局变量模型。
局部声明生成词法作用域内的 `let`，复制声明及其后续语句时优先绑定到副本；
重命名、增减与撤销保留绑定。变量增减提供同 KN 的“增加／减少”选项。
列表复制替换目标内容并保留目标引用，先获取源的浅副本以支持自身复制。

`src/blocks/index.js` 必须先加载 Blockly 内置定义，再加载加减号插件、自定义块和统一定义配置。
`src/blocks/definitions.js` 按工具栏分类设置样式，补充动态函数块，并通过 `setInputsInline(true)` 配置布局。

运行 `npm test` 可验证整个工具栏的反序列化、预览状态不丢失、参数增减与分支重排，
以及循环变量/列表绑定、嵌套控制、函数、列表的存取和代码生成。
`tests/layout.test.js` 额外使用未知类型名和输入名，验证结构判断、隐藏字段、操作区位置与预览继承。
`tests/fixtures/block-styles.boxy` 是可在 Boxy 中打开的检查样例。
浏览器中还应检查控制嵌套、布尔输入、动态加减号、数字编辑、缩放和积木图片导出。
视觉回归页与对照方法见 `tests/visual/README.md`。
