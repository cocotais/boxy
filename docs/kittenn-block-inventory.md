# KittenN 积木清单核对

核对日期：2026-11-27。参考用户打开的 KittenN 作品编辑器，逐类读取积木盒中
所有顶层积木（包括滚动区域之外的积木），并与 `src/assets/toolbox.json`、
`src/blocks/toolbox.js`、积木定义和预览描述核对。

本记录核对入口与定义的对应关系，不代表全部下拉选项、运行语义或工作区样式
已经逐项验证。此前的共有积木尺寸对照不能代替清单核对。

## 本轮调整结果

- 运算盒按 KN 的顺序分开展示四则运算、四种比较、且／或，保留用户要求的独立数值和字符串。
  移除查找字符、截取、替换、计数、大小写转换与去除空白六个额外入口，补充文本包含。
- “更多函数运算”的七个选项已经在 KN 下拉中逐项确认，与 Blockly `math_single` 对应；
  使用相同的简略预览，默认参数改为 0。
- 文本拆分只保留拆分功能，工作区默认值为 `a,b,c` 和逗号；积木盒保留 KN 的简略 `abc` 预览。
- 变量盒补充脚本变量声明、末尾加减号、可拖出的取值块、重命名和保存恢复。
  脚本变量不进入全局变量列表，只能在声明之后所在的词法作用域使用；
  变量选择器可选择所在作用域的脚本变量，“增加变量”支持切换为“减少”。
- 列表盒按 KN 顺序排列，补充复制列表，移除单独创建空列表；临时列表仍可减到零项。
  复制使用源列表的浅副本替换目标内容，保留目标引用，自身复制不会清空数据。
- 不加入变量／列表的显示与隐藏；控制盒移除遍历列表和条件取值。
- 控制盒其他缺项、KN 事件运行时和函数方案不在本轮修改范围内。

以下保留调整前的核对记录，便于追溯入口差异。

## 控制（调整前）

KN 当前有 13 个预览，Boxy 有 9 个预览，其中“如果”有两个预设。

| KN             | Boxy                           | 核对结果                             |
| -------------- | ------------------------------ | ------------------------------------ |
| 永远循环       | `controls_forever`             | 有对应入口                           |
| 循环若干次     | `controls_repeat_ext`          | 有对应入口                           |
| 遍历起止数值   | `controls_for`                 | 有对应入口                           |
| 循环直到       | `controls_whileUntil`          | 有对应入口，Boxy 下拉还提供 WHILE    |
| 退出循环       | `controls_flow_statements`     | 有对应入口，Boxy 下拉还提供 CONTINUE |
| 如果           | `controls_if`                  | 有对应入口                           |
| 如果／否则     | `controls_if`，`hasElse: true` | 有对应入口                           |
| 等待           | 无                             | 缺少                                 |
| 等待直到       | 无                             | 缺少                                 |
| 控制台提示     | 无                             | 缺少                                 |
| 一步执行       | 无                             | 缺少，需要核对调度语义               |
| 告诉角色       | 无                             | 缺少，依赖 KN 角色运行时             |
| 告诉角色并等待 | 无                             | 缺少，依赖 KN 角色运行时             |

Boxy 额外显示“遍历列表” `controls_forEach`、
“条件取值” `logic_ternary`。

## 运算（调整前）

KN 当前有 25 个预览，Boxy 也有 25 个预览，但组成不同。
不能用总数判断对齐，也不能只按 block type 去重后计数。

| KN                      | Boxy                            | 核对结果                                                        |
| ----------------------- | ------------------------------- | --------------------------------------------------------------- |
| ＋、－、×、÷，四个入口  | 一个 `math_arithmetic` 入口     | 可通过下拉切换，积木盒缺少三个预设入口                          |
| ＝、≠、＞、＜，四个入口 | 一个 `logic_compare` 入口       | 可通过下拉切换，积木盒缺少三个预设入口                          |
| 且、或，两个入口        | 一个 `logic_operation` 入口     | 可通过下拉切换，积木盒缺少一个预设入口                          |
| 随机整数                | `math_random_int`               | 有对应入口                                                      |
| 不成立／成立            | `logic_negate`／`logic_boolean` | 有对应入口                                                      |
| 四舍五入                | `math_round`                    | 有对应入口                                                      |
| 余数                    | `math_modulo`                   | 有对应入口                                                      |
| 能被整除                | `math_evenly_divisible`         | 有对应入口                                                      |
| 质数判断                | `math_number_property`          | 有对应入口                                                      |
| sin                     | `math_trig`                     | 有对应入口                                                      |
| 更多函数运算            | `math_single`，默认算术平方根   | 入口文案与预览不同；全部函数选项尚未逐项核对                    |
| 连接                    | `text_join`                     | 有对应入口                                                      |
| 指定位置字符            | `text_charAt`                   | 有对应入口                                                      |
| 字符总数                | `text_length`                   | 有对应入口                                                      |
| 文本包含                | 无直接对应入口                  | 缺少；查找位置、出现次数不是相同入口                            |
| 把文本分开              | `lists_split`                   | 简略预览有对应；Boxy 完整定义还包含分隔符与合并模式，语义需另核 |
| 转换数据类型            | `math_types`                    | 有对应入口                                                      |

Boxy 额外显示：

- 独立数值 `math_number`、独立字符串 `text`：此前用户明确要求保留并使用一参数连接的外观。
- 查找字符 `text_indexOf`。
- 截取文本 `text_getSubstring`。
- 替换 `text_replace`。
- 出现次数 `text_count`。
- 大小写转换 `text_changeCase`。
- 去除空白 `text_trim`。

这里“额外显示”指 KN 当前运算盒中没有独立的对应入口，
不推断 KN 的全部下拉菜单或其他编辑上下文中都没有相关能力。

## 函数与事件

KN 当前主编辑器的函数盒中有一个用户函数的调用预览。
定义、返回等内容受函数编辑上下文影响，不能据此判断 KN 缺少这些功能。
Boxy 当前在同一函数盒展示统一定义、独立返回，并为每个函数生成
语句调用与取值调用两种入口。展示位置与数量不同；函数功能差异此前已获用户接受。

KN 事件盒当前有 22 个预览，涉及开始运行、点击、滑动、按键、碰撞、条件、
广播、停止／重启、屏幕切换与克隆。Boxy 当前没有事件分类。
它们大多需要角色、屏幕、广播或克隆运行时，不属于仅调整主题即可补齐的内容。

## 处理边界

调整后的清单通过 `tests/inventory.test.js` 验证；测试也覆盖文本运算、
列表复制引用、脚本变量读写与增减、撤销、复制和保存恢复。
