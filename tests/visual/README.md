# 主题视觉回归

先运行 `npm run dev`，再通过浏览器打开以下页面。两页都加载实际 Boxy 应用、字段、
渲染器和积木盒，不向生产应用暴露测试接口。

- `/tests/visual/theme.html`：按钮分别加载控制、运算、变量、列表、函数、动态参数和函数体场景。
  包括全部工具栏定义、不同长度的变量/列表名、多个分支、函数参数、长文本和小数。
  `scriptVariables` 场景检查局部声明、名称选择、增加／减少及拖出取值块。
- `/tests/visual/generic.html`：点击 `workspace pairs` 比较八组原积木和新积木；
  点击 `flyout pairs` 在真实积木盒中比较同一批积木的简略预览。

新积木使用未知类型名，数值、文本、变量标签与条件块重新定义；条件块还使用
`WHEN / BODY / ACTIONS` 等不同输入名。其余积木复用定义，验证字段角色与 `boxyPreview`
元数据能够继承。每对积木的可见 SVG、尺寸和样式应该一致，位置与类型类名除外。

`snapshot.mjs` 导出可序列化的只读 DOM 投影 `snapshotTheme`，用于浏览器自动化的
`playwright.evaluate(snapshotTheme)`。它记录各积木的相对坐标、SVG 路径、字段文字、
颜色、字体、光标、滤镜和编辑器边界，并归一化工作区生成的随机滤镜 ID。

修改渲染规则前后使用相同窗口、缩放和场景进行对比：

1. 六个工作区场景分别记录 DOM 投影及整页截图。
2. 在变量场景分别打开控制、运算、变量、列表和函数分类，等待 300ms 开合动画结束后记录。
3. 在运算场景打开加减乘除下拉，选择“乘以”，分别记录打开与关闭状态。
4. 在列表场景打开“添加项到末尾”的列表胶囊下拉，选择 `a`，分别记录打开与关闭状态。
5. 在运算场景点击独立数值字段，等待 250ms 外圈动画结束后记录，Escape 退出编辑。
6. 在控制场景悬停“永远循环”，记录滤镜与光标；截图比较时另行检查滚动条淡入淡出。

这共 17 个状态。截图应逐像素比较；SVG 路径若只有等价的命令写法变化，必须再用截图
确认形状相同。不要通过忽略所有路径变化掩盖轮廓回归。新积木的八组对照也应在工作区
与真实积木盒两种上下文中执行。

包含 `functionBody` 及结构对照页后共 20 个静态/交互状态。对照前完整加载两个版本，
避免模块热更新累积 Blockly 定义包装或留下过期预览描述；固定相同视口、像素密度，
截图时两个页面均置于前台，避免桌面指针只出现在其中一张截图。
SVG 投影包含全部积木；像素对照可使用同一裁剪区域并排除页面边缘的原生浏览器滚动条，
不能排除积木、字段、菜单、白边或悬停滤镜。完全隐藏字段的 SVG 属性变化应单独列出，
不能据此忽略任何可见轮廓或颜色差异。

拼接与拆开还应执行以下动态检查：

1. 变量场景中，将“设置变量”的语句块拖到“增加变量”下方，按住鼠标检查占位。
   占位应为 110×40，只有黑色半透明外轮廓，默认数值胶囊与字段均不可见。
2. 控制场景中，把“遍历”拖进“永远循环”的语句槽。占位应为 110×80 的空 C 形剪影，
   移开时槽位恢复原大小；放下后保留完整的起止值、当前变量和步长按钮。
3. 拆开刚拼接的块，检查积木跟随鼠标，不倾斜摆动；松手拼接时应出现 150ms 白色实心光点，
   不显示灰色圆环，结束后不残留圈或占位模型。执行撤销、重做检查连接关系。
4. 把值输出积木插入参数槽，再拖出；检查圆形/布尔槽的替换高亮、默认 shadow 的恢复，
   并检查从积木盒、循环变量字段拖出的积木也有相同反馈。

函数参数交互：在函数场景检查统一定义的末尾加号。加号先弹出名称对话框，
确认后出现橙色参数胶囊；取消、空名称及重复名称不能产生多余参数。
从胶囊拖出取值积木，检查原定义不移动、原参数保留，拖出前后胶囊尺寸一致；
可把取值积木接入独立返回块的值槽。点击定义处的胶囊重命名，已有取值积木与调用处
应同步更新。新增、移除与拖出后分别检查撤销重做，并保存、重新打开作品检查绑定。

`functionBody` 场景加载两个统一函数头，其中一个函数体末尾带有独立返回块。函数体应从主体
左下角以 0 缩进直列连接，连接点为 `(0, 40)` / 带参数时 `(0, 44)`，徽标向上、向左突出。
头部无 C 形竖边与底臂；返回块左下角为 12px 圆角，下方无连接口，值输入不越出背景。
还应从函数体中拖出、接回语句，确认头部轮廓和连接位置稳定；积木盒中的空定义也应显示圆形徽标。

`function` 场景包含短名称 `a` 的执行积木和两种返回状态：执行积木背景宽度应为 110px，
值积木的尺寸不受此规则影响。“返回”默认有一个数值输入和末尾减号，点击后只剩返回文字及加号，
再点击加号恢复数值 0。接入普通取值积木后点减号，应将取值积木释放到工作区，撤销后恢复连接。
检查两种状态保存、重开后仍正确，积木盒始终为简略的“返回”，拖出默认带一个参数。
